# Exercícios de Lógica de Programação em Java

Repositório dedicado à prática e ao desenvolvimento de conhecimentos em **lógica de programação utilizando Java**.

O objetivo é desenvolver o raciocínio lógico e a capacidade de resolução de problemas por meio de exercícios práticos, explorando estruturas fundamentais da programação e os recursos básicos da linguagem Java.

## Conteúdos praticados

- Variáveis e tipos de dados;
- Operadores aritméticos e lógicos;
- Estruturas condicionais (`if`, `else`, `switch`);
- Estruturas de repetição (`for`, `while`, `do-while`);
- Manipulação de Strings;
- Vetores e matrizes;
- Funções e métodos;
- Entrada e saída de dados;
- Operações matemáticas e resolução de problemas.
